# JRiver Remote 2.5.1

## Highlights

- **Fixed Artist Albums Refresh.** Corrected a logic error where the refresh button on the Artist Albums screen would not trigger a new network request, causing it to display stale data.

## Fixes

### Library

- **Provider Invalidation**: The "Refresh" action now correctly invalidates the source data provider (`albumsByArtistProvider`) instead of just the derived grouping provider. This ensures a fresh fetch from the JRiver server and immediate UI updates.

## Migration notes for developers

- No breaking changes or new architectural requirements in this patch.
