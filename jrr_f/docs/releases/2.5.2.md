# JRiver Remote 2.5.2

## Highlights

- **Queue UI Smoothness.** Optimized the Queue screen to prevent unnecessary loading flickers during state updates, providing a more fluid playback management experience.
- **Updated Design System.** Significant updates to design assets and components, including new foundations for the settings interface.
- **Offline Mode Specifications.** Enhanced technical documentation with best practices for robust offline startup and synthetic session management.

## Improvements

### Queue

- **State Loading Optimization**: Implemented `skipLoadingOnReload: true` in the `QueueScreen`. This ensures that when the queue data is refreshed, the UI maintains its current state instead of reverting to a loading spinner, significantly improving perceived performance.
- **Logging Refinement**: Cleaned up debug logging in the queue feature to reduce noise and improve maintainability.

### Design & Assets

- **Component Updates**: Added new design components for settings (`jrr-settings.jsx`) and refined existing player components.
- **Asset Reorganization**: Streamlined the design directory by removing obsolete standalone files and reorganizing script/component assets for better developer ergonomics.

### Documentation

- **Robustness Guidelines**: Updated `SPEC.md` with version 2.5.1/2.5.2 insights, specifically focusing on "Offline Mode" architecture.
- **Best Practices**: Added detailed guidance on provider decoupling and async synchronization to ensure the app's core remains stable under various network conditions.

## Migration notes for developers

- No breaking changes in this release. Developers should review the updated `SPEC.md` for new patterns regarding offline-first state management.
