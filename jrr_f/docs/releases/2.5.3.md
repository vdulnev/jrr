# JRiver Remote 2.5.3

## Highlights

- **Efficient Resource Management.** Introduced app lifecycle management to automatically pause network polling when the app is in the background, conserving battery and data.
- **Manual Zone Refresh.** Added a refresh button to the zones list for quick manual updates.

## Improvements

### Core

- **Lifecycle Awareness**: Implemented `AppLifecycleProvider` using `AppLifecycleListener`. This feature intelligently pauses playback and zone status polling when the app is paused (backgrounded) and resumes it upon return, optimizing system resource usage.
- **Global Integration**: Connected the lifecycle listener to the root application state to ensure consistent behavior across all features.

### Zones

- **Refresh Capability**: Added a dedicated refresh button to the "Zones" screen header. This provides users with a direct way to trigger a manual reload of available playback zones.
- **UI Refinement**: Updated the zones header layout to accommodate the new refresh action while maintaining a clean, consistent design.

### Maintenance

- **Ignore Local Logs**: Updated project configuration to exclude local log files from version control.

## Migration notes for developers

- No breaking changes in this release. The new `appLifecycleProvider` is automatically initialized in the `RootScreen`.
